01 THE WAY I WORK

시스템을 이해하는 시선.
동작으로 확인하는 개발.

기계설계에서 시작해 센서와 계측을 연구하고, 임베디드 SW로 다루는 범위를 넓혔습니다. 물리적인 신호가 코드의 판단을 거쳐 실제 동작으로 이어지는 과정을 이해하고 구현합니다.

01

구현의 근거를 세웁니다.

요구사항을 제어·진단 로직으로 구체화합니다. 신호의 입력과 출력, 통신 인터페이스를 함께 살핍니다.

REQUIREMENTS → CODE
02

분석의 범위를 넓힙니다.

코드에서 해결되지 않으면 전원과 HW, 입력 데이터까지 확인합니다. 증상에 맞춰 판단의 근거를 다시 찾습니다.

SOFTWARE ↔ HARDWARE
03

실제 동작으로 확인합니다.

정적 분석과 단위·통합시험을 거쳐 실제 HW와의 동작을 시험합니다. 수정한 항목은 다시 검증합니다.

IMPLEMENT → VERIFY

02 SELECTED WORK

직접 판단하고 구현한 범위를 담았습니다.
