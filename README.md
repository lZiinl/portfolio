# 조정훈 HTML 포트폴리오

설치 없이 `index.html`을 브라우저로 열면 볼 수 있는 한국어 정적 포트폴리오입니다. HTML, CSS, Vanilla JavaScript로 구성했으며 외부 폰트·라이브러리·분석 도구를 불러오지 않습니다.

## 열기

- `index.html`을 더블클릭합니다. 프로젝트 상세 페이지도 파일 상태에서 작동합니다.
- 로컬 서버를 이용하려면 Node.js 20 이상에서 `npm start`를 실행한 뒤 `http://127.0.0.1:4173`을 엽니다. 종료는 `Ctrl+C`입니다.
- 다른 포트를 사용하려면 PowerShell에서 `$env:PORT = '4174'`를 지정하고 `npm start`를 실행합니다.

## 수정

1. `data/portfolio.mjs`에서 프로필, 프로젝트, 경력, 기술, 연구·자격 정보를 수정합니다.
2. `npm run build`로 메인 HTML과 프로젝트 상세 HTML을 다시 생성합니다.
3. `npm run check`로 링크·앵커·콘텐츠 제외 항목을 점검합니다.

생성된 HTML의 본문을 직접 수정하면 다음 빌드에서 덮어씁니다. 문구는 데이터 파일에서, 화면 구조는 `scripts/build.mjs`에서, 디자인은 `assets/styles.css`에서, 상호작용은 `assets/main.js`에서 수정하세요. 패키지 설치는 필요하지 않습니다.

## 파일 구성

| 파일 | 용도 |
| --- | --- |
| `index.html` | 소개, 대표 프로젝트, 경력, 기술, 연구·자격 |
| `projects/*.html` | 7개 프로젝트의 역할·판단·실행·검증 상세 |
| `data/portfolio.mjs` | 공개 화면에 사용한 콘텐츠 원본 |
| `data/media.mjs` | 프로젝트별 이미지, 크기, 대체 텍스트, 설명 |
| `assets/images/` | 제공 PDF에서 추출해 사용한 프로젝트 이미지 |
| `assets/motion/` | 클릭해서 재생하는 로봇 시연 GIF 원본 |
| `scripts/build.mjs` | 정적 HTML 생성 템플릿 |
| `scripts/serve.mjs` | 로컬 미리보기 서버 |
| `scripts/check.mjs` | 내부 링크 및 기본 콘텐츠 점검 |
| `assets/styles.css` | 데스크톱·모바일·인쇄 스타일 |
| `assets/media.css` | 시연 플레이어와 논문 실험 자료 레이아웃 |
| `assets/main.js` | 메뉴·필터·섹션 표시·개념도 상호작용 |

## 프로젝트 추가

`projects` 배열에 기존 항목과 같은 구조로 객체를 추가합니다. `id`는 소문자 영문·하이픈으로 작성하고 중복되지 않게 지정합니다. `featured: true`이면 메인 카드, `false`이면 추가 연구 목록에 나타납니다. `actions`는 제목과 설명의 배열이며, `details`는 펼쳐 읽는 추가 설명입니다. 새 유형의 개념도가 필요하면 `artwork()`에 추가합니다. 기존 기본 도식은 실물이나 실측 데이터를 재현하지 않습니다.

## 연락처·자료 추가

- 확정된 이메일을 `profile.email`에 넣고 빌드하면 연락처 영역이 표시됩니다.
- GitHub와 이력서 링크는 현재 표시하지 않습니다. 실제 공개 저장소·PDF를 받은 후 템플릿에 검증된 경로를 추가하세요. `profile.github`, `profile.resume`은 확장을 위한 예약 필드입니다.
- 실물 사진이나 정확한 논문 DOI를 추가할 때는 공개 가능 여부와 실제 경로를 확인하세요.
- 재직 상태가 변경되면 `experience`와 MCU 프로젝트의 기간·기간 설명, 프로필 기준일을 갱신하세요. 현재 정보 기준일은 2026.10.14입니다.

## 포함 기능

- 모든 본문이 HTML에 있어 JavaScript가 꺼져도 읽을 수 있습니다.
- 주요 프로젝트 분야 필터, 모바일 메뉴, 현재 섹션 표시, 상세 페이지와 다음 프로젝트 이동.
- 키보드 포커스, 본문 건너뛰기, `prefers-reduced-motion` 대응.
- 인쇄 시 프로젝트 필터를 무시해 모든 카드가 출력됩니다. 접힌 상세 이력도 인쇄 시 펼칩니다.
- 상대 경로를 사용해 파일 직접 열기 및 GitHub Pages 하위 경로에 대응합니다.

## 배포 범위

현재는 로컬 결과물입니다. 외부에 배포하지 않았습니다. 추후 배포 시 필요한 파일은 `index.html`, `projects/`, `assets/`입니다. 제공받은 마크다운 원문, 개인정보 메모, 회사 내부 자료는 복사하거나 배포 폴더에 넣지 않았습니다. 로컬 서버도 웹사이트 파일만 제공합니다.

## 검증

`npm run check`는 8개 HTML의 내부 파일 링크·앵커·중복 ID·언어·제목과 일부 제외 대상 문자열을 검사합니다. 이는 접근성 전체 감사나 모든 사실에 대한 외부 증빙 검증은 아닙니다. 수정 후에는 360px 모바일, 데스크톱, 인쇄 미리보기에서 레이아웃과 메뉴·필터·상세 링크를 함께 확인하세요.

초기 제작에서는 위 정적 검사와 JavaScript 구문 검사를 통과했습니다. 브라우저 도구의 로컬 사이트 접근 승인이 거절되어 실제 브라우저에서의 화면·클릭·인쇄 검수는 수행하지 못했습니다.

## PDF 자료 반영 (2026.10.15)

로봇 구성도, AGV 대시보드, LNG 시험 장치·시스템 구성도, CNT 실험 사진과 모델 비교·SHAP 그래프, 로드셀 시제품·계측 사진 총 10개 원본 이미지 객체를 추출해 반영했습니다. 이미지 자체에 새로운 그래프나 수치를 합성하지 않았습니다. 메인 카드와 상세 페이지 자료 영역에서 사용하며, 상세 이미지를 클릭하면 원본 크기로 새 탭에서 열립니다. 그래프의 축과 범례를 보존하고, 데이터 조건과 해석 범위를 캡션에 적었습니다.

이미지 교체는 `data/media.mjs`의 경로·크기·설명을 변경하고 `npm run build`를 실행하면 됩니다. 이후 ZIP을 새로 만들려면 PowerShell에서 `Compress-Archive -LiteralPath index.html,assets,projects -DestinationPath Jeonghun_Portfolio.zip -Force`를 실행하세요.

사용자가 2026.10.15에 같은 로드셀 연구이며 PDF 기간이 맞다고 확인하여, 연구 기간을 2021.11~2022.10으로 정정하고 시제품·계측 사진을 상세 페이지에 반영했습니다. 원본 PDF와 검토용 추출 자료는 배포하지 않습니다. PDF에서 확인한 AGV 프로젝트 기간과 개인 담당 범위는 콘텐츠에 보완했습니다.

## 로봇 시연·석사논문 반영 (2026.10.15)

- 로봇 페이지에 GIF 4개를 추가했습니다. 원본 파일은 변경하지 않고 복사했으며, 첫 프레임을 정지 미리보기로 추출했습니다. 메인 로봇 카드에도 실제 로봇의 정지 화면을 사용합니다.
- GIF 원본은 총 약 47.2MB입니다. 페이지를 열 때는 작은 정지 화면만 요청하고, 재생 버튼을 눌러야 GIF를 불러옵니다. 한 번에 하나만 재생하며 정지하면 첫 화면으로 돌아갑니다. 재생 종료, 탭 숨김, 인쇄, 접힌 시연 영역, 동작 줄이기 설정 변경에도 정지합니다. JavaScript를 사용할 수 없으면 원본 GIF 링크로 열 수 있습니다.
- 로봇 매핑은 팀의 ROS·LiDAR SLAM 기능으로 설명하고, 개인 담당인 기구·전원·계측·제어·MQTT 연동과 구분했습니다.
- 석사논문 Fig. IV-3·IV-4의 원본 이미지로 게이지 계수 측정 사진과 모델 비교 그림을 교체했습니다. Fig. V-2~V-7은 온도 보상 전용 영역에 추가했습니다.
- Fig. V-7은 타입별 최적 사례를 선택한 비교이며 전체 평균이 아닙니다. 시간(s)·출력(mV/V) 축과 범례를 보존했습니다. Quarter 시편 3개, Half 3쌍(6개), Full 3세트(12개)의 개별 결과는 펼침 영역에서 확인합니다.
- 논문 본문 49쪽에 따라 20~80℃ 보상 실험, 1,000배 증폭·필터링·DAQ 수집, 별도 실시간 온도 계측 없이 선형 온도 변화를 가정한 조건을 명시했습니다. 사전 온도 의존성 실험의 20~90℃ 조건과 구분합니다.
- 학위논문 PDF 전체는 배포하지 않습니다. 이전에 거절된 브라우저 접근을 재시도하지 않았으므로 새 플레이어의 실제 브라우저 클릭·인쇄 동작 검수는 수행하지 못했습니다.
