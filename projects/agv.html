PROJECT 03 / AGV / DATA ANALYSIS

영상 학습 기반 AGV 주행 안정화

제어값 조정으로 해결되지 않은 지그재그 주행. 판단의 근거가 되는 이미지부터 다시 확인했습니다.

IN THIS PROJECT

배경과 목표판단과 실행검증과 결과역할과 해석 범위

01 / CONTEXT

어떤 문제를 다뤘는가.

카메라 이미지 학습 기반 AGV가 직선에서도 지그재그로 주행했습니다. 제어 파라미터를 조정해도 해결되지 않아, 제어 판단의 근거인 학습 데이터 구성을 확인했습니다.

02 / APPROACH

어떻게 판단하고 실행했는가.

01

약 2,500장 전수 확인

학습 이미지를 전수 검토해 특정 각도·조건의 데이터가 70% 이상으로 편중된 점을 발견했습니다.

02

제약에 맞춘 데이터 조정

추가 촬영이 어려운 일정에서 데이터 비중을 조절하고 이미지 반전, 노이즈 추가 등으로 데이터를 증강했습니다.

03

재학습 후 주행 확인

조정한 데이터로 재학습한 뒤 직선 주행 안정화를 확인했습니다. 이후 시간을 차량 상태 모니터링과 제어 기능 개발에 활용했습니다.

04

상태 모니터링과 제어 연동

Raspberry Pi로 센서 데이터를 수집하고 MQTT로 연동했습니다. Node-RED 대시보드에서 상태 확인과 목적지·제어모드 변경 기능을 구현하고 Firebase와 CSV로 데이터를 기록했습니다.

03 / VERIFICATION

동작과 결과를 확인하다.

추가 현장 데이터 수집 없이 직선 주행을 안정화했습니다. 제어 파라미터뿐 아니라 입력 데이터의 구성까지 분석 범위를 넓혀 해결했습니다.

04 / SCOPE

직접 수행한 범위.

약 2,500장과 70% 이상은 검토한 데이터 수와 편중 비율입니다. 정확도나 주행 성능의 향상률을 의미하지 않습니다.
