IN THIS PROJECT

배경과 목표판단과 실행검증과 결과역할과 해석 범위

01 / CONTEXT

어떤 문제를 다뤘는가.

차량용 램프 제어 SW는 제어·진단 기능의 구현과 함께 실제 HW와의 동작 확인이 필요합니다. 요구사항 분석부터 설계, 구현, 정적 분석과 시험에 참여했습니다.

02 / APPROACH

어떻게 판단하고 실행했는가.

01

제어·진단 구현

NXP Kinetis, S32K144, PIC 기반으로 C 제어·진단 로직을 구현했습니다. ADC로 전압과 진단 신호를 계측하고 GPIO와 PWM 출력을 제어했습니다.

02

정적 분석과 SW 시험

Polyspace로 MISRA-C와 CWE 분석 결과를 검토하고 코드를 수정·재검증했습니다. VectorCAST 기반 단위시험과 통합시험을 수행했습니다.

03

인터페이스와 추적성

CAN, LIN, UART 관련 개발과 HW 연동 시험을 수행했습니다. Codebeamer로 요구사항, 설계, 검증 항목 사이의 추적성을 구축·관리했습니다.

03 / VERIFICATION

동작과 결과를 확인하다.

구현한 기능을 단위·통합시험과 실제 HW 연동 시스템 시험으로 확인했습니다. 검출된 항목은 수정 후 다시 시험했습니다.

04 / SCOPE

직접 수행한 범위.

여러 업무와 프로젝트에서 수행한 내용을 정리했습니다. A-SPICE 공식 담당 범위는 한 프로젝트의 SWE.4~SWE.6, 사내 Pilot Project의 SWE.3~SWE.5입니다.

개발 환경과 협업＋

Git 기반 소스 형상관리, 사내 형상관리 프로그램 유지보수, 팀 형상관리 가이드 개정에 참여했습니다. MATLAB/Simulink 기반 MBD 선행개발도 수행했습니다.
