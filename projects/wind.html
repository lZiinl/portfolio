PROJECT 07 / DESIGN / EXPERIMENT

빌딩풍 분석과 3D 프린팅 풍력발전기

빌딩풍 문제를 분석한 팀에서 풍력발전기 제작과 성능 평가를 담당했습니다.

구분연구
기간2020부경대학교 실전문제연구단
내 역할풍력발전기 제작·시험, 동료의 2D 유동 해석 지원
  • 3D 프린팅
  • CFD
  • 제작·시험

IN THIS PROJECT

배경과 목표판단과 실행검증과 결과역할과 해석 범위

01 / CONTEXT

어떤 문제를 다뤘는가.

교내 공학관 천장재 이탈 문제를 계기로 팀에서 빌딩풍을 분석했습니다. 관련 논문 약 20편을 검토하고 벤투리 효과에 따른 압력 저하 가설을 2D·3D CFD로 검토했습니다.

02 / APPROACH

어떻게 판단하고 실행했는가.

01

제작과 해석 지원

풍력발전기 제작과 시험을 맡고, 어려움을 겪는 동료의 2D 해석을 지원했습니다.

02

파손 원인에 따른 보완

3D 프린팅 블레이드가 층간 강도 문제로 파손되어 아세톤 훈증 표면처리 후 다시 시험했습니다.

03 / VERIFICATION

동작과 결과를 확인하다.

풍력발전기 제작과 성능 평가를 수행했습니다. 관련 프로젝트로 2020 X-CORPS 경진대회 금상(PKNU실전문제연구단) 등을 수상했습니다.

04 / SCOPE

직접 수행한 범위.

CFD 분석은 팀의 접근이며, 제가 수행한 해석 역할은 동료의 2D 해석 지원입니다.
